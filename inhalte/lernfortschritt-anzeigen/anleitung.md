# Anleitung: Wunsch-Feature: Lernfortschritt anzeigen

Lernwerk Nord ist fiktiv – synthetische Schulungsdaten.

## Worum es geht

Sie zeigen Lernenden auf der Übersicht, welche Lernpakete begonnen und welche abgeschlossen sind.

## Ihr Auftrag

Arbeiten Sie in der Übungscodebasis des Lernpakets. Beschreiben Sie dem Agenten zuerst das Ziel in zwei Sätzen, lassen Sie ihn einen Plan vorschlagen und geben Sie ihn frei, bevor er Dateien ändert.

## Fertig, wenn

Das Ergebnis läuft, und Sie können in einem Satz erklären, was der Agent geändert hat.
