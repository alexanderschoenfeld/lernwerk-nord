Agenten auf einen Blick

Erklärseite zum Lernpaket „Ein Agent für Routineaufgaben“. Weiter mit der Schaltfläche.

1. Worum es geht: Sie lassen einen Agenten eine wiederkehrende Aufgabe in einer kleinen Codebasis erledigen und prüfen das Ergebnis.
2. Was der Agent dabei tut: Er liest die Dateien, schlägt Änderungen vor und führt sie nach Ihrer Freigabe aus.
3. Was Sie prüfen: ob das Ergebnis läuft und ob der Agent nur geändert hat, was verlangt war.
