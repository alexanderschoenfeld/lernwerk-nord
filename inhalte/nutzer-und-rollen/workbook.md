# Workbook: Nutzer und Rollen verwalten

Lernwerk Nord ist fiktiv – synthetische Schulungsdaten.

**Dauer:** höchstens 55 Minuten · **Niveau:** fortgeschritten · **Thema:** Nutzerverwaltung

Sie ergänzen eine Anmeldung um Rollen und prüfen, dass jede Rolle nur sieht, was sie sehen darf.

## Aufgaben

1. Lesen Sie die Anleitung bis zum Abschnitt „Ihr Auftrag“.
2. Öffnen Sie die Erklärseite und notieren Sie die drei Begriffe, die sie erklärt.
3. Erledigen Sie den Auftrag aus der Anleitung mit Ihrem Agenten.
4. Halten Sie fest, was der Agent gut gemacht hat und wo Sie nachbessern mussten.
